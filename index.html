Gagasan utama

R′(t) = (Ri+1 − Ri) / (ti+1 − ti)

Selisih RAM dibagi selisih waktu menghasilkan laju perubahan dengan satuan GB/jam.

Data pada situs ini adalah simulasi untuk demonstrasi konsep matematika, bukan hasil pengukuran Adobe Photoshop.

Latar belakang dan tujuan

Latar belakang

RAM adalah memori yang digunakan komputer untuk menyimpan data sementara ketika aplikasi berjalan.

Penggunaan RAM dapat berubah mengikuti aktivitas aplikasi, dokumen yang dibuka, ukuran proyek, plugin, serta kondisi sistem. Perubahan tersebut tidak harus linear dan tidak selalu bertambah ketika aplikasi digunakan lebih lama.

Turunan dapat digunakan untuk mempelajari laju perubahan suatu besaran terhadap waktu.

Tujuan penelitian

Mendemonstrasikan penerapan turunan melalui data simulasi penggunaan RAM terhadap durasi penggunaan Adobe Photoshop.

Pertanyaan yang dijawab pada halaman ini: seberapa cepat penggunaan RAM simulasi berubah pada tiap selang waktu, dan bagaimana laju itu dihitung dari data.

Ubah data

  • Durasi dan RAM harus berupa angka lebih besar dari 0. Koma atau titik boleh dipakai sebagai pemisah desimal.
  • Durasi tidak boleh sama dengan durasi yang sudah ada. Data diurutkan otomatis dari durasi terkecil.
  • Untuk mengubah nilai, ketik langsung pada tabel lalu tekan Enter atau pindah kolom. Perubahan valid tersimpan otomatis.
  • Minimal dua titik data harus tersisa agar interpolasi dan grafik dapat dihitung.
  • Data disimpan di browser dan perangkat ini saja (localStorage). Perubahan tidak dibagikan ke pengunjung lain karena situs ini tidak memakai server.

Model matematika dan turunan

Definisi

  • t: durasi penggunaan aplikasi (jam).
  • R(t): penggunaan RAM simulasi (GB).
  • R′(t): laju perubahan penggunaan RAM (GB/jam).

Turunan menyatakan laju perubahan penggunaan RAM terhadap waktu. Satuannya GB dibagi jam, yaitu GB/jam.

Interpolasi linear per interval

Untuk dua titik berurutan (ti, Ri) dan (ti+1, Ri+1):

R(t) = Ri + [(Ri+1 − Ri) / (ti+1 − ti)] (t – ti)

untuk ti ≤ t ≤ ti+1. Di bagian dalam setiap interval, turunannya adalah:

R′(t) = (Ri+1 − Ri) / (ti+1 − ti)

Turunan pada titik data

Karena model berbentuk garis-garis yang disambungkan, turunan tepat di titik sambungan tidak selalu ada. Pada titik data internal, kemiringan interval kiri dan kanan dibandingkan. Jika berbeda, turunan dua sisi tidak terdefinisi. Pada titik awal dan akhir hanya tersedia turunan satu sisi dalam domain data. Tidak ada ekstrapolasi di luar durasi minimum dan maksimum.

Kalkulator laju perubahan

Laju perubahan rata-rata

[R(t₂) – R(t₁)] / (t₂ − t₁)

Ringkasan hasil dan kesimpulan

Kesimpulan otomatis

Batasan penelitian

  1. Data yang digunakan merupakan data simulasi, bukan pengukuran perangkat nyata.
  2. Model hanya menunjukkan hubungan matematis yang dibuat untuk demonstrasi konsep turunan.
  3. Penggunaan RAM aktual dipengaruhi oleh spesifikasi komputer, sistem operasi, versi aplikasi, ukuran file, plugin, dan aktivitas pengguna.
  4. Model interpolasi linear mengasumsikan perubahan linear di antara dua titik data berurutan.
  5. Hasil tidak dapat digunakan untuk memprediksi performa Adobe Photoshop secara nyata tanpa pengukuran dan validasi empiris.

Tentang penyimpanan data

Perubahan data disimpan melalui localStorage, sehingga hanya tersimpan pada browser dan perangkat yang Anda gunakan. Perubahan tidak otomatis dibagikan ke pengunjung lain karena situs di-hosting melalui GitHub Pages tanpa backend. Menghapus data situs di browser akan mengembalikan data ke nilai simulasi awal.
